Welcome to my First Task

This is a responsive collapsible sidebar built with pure HTML, CSS, and JavaScript. The sidebar features smooth transitions, responsive behavior, and clean modern styling.

On desktop, the sidebar is visible by default and can be toggled using the hamburger menu. On mobile devices, the sidebar is hidden by default and slides in from the left when opened.

Try resizing your browser window to see how the sidebar adapts to different screen sizes, or click the toggle button to see the smooth slide animation in action.
